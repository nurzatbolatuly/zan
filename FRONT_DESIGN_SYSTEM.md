# Zan — Design System (зафиксированные токены)

Единственный источник значений для стилей. Ничего из этого файла не подбирается "на глаз" повторно в коде — если нужного значения нет здесь, оно сначала добавляется сюда (с обоснованием), потом используется.

Источник: `Design/Zan.dc.html` (прототип уже задаёт палитру и шрифты, Zan.dc.html:14-35) — этот документ формализует то, что в прототипе было расставлено вручную по инлайн-стилям, в контролируемую шкалу. Реализуется в `shared/styles/tokens.css` + `tailwind.config` на Stage 0 (см. `PLAN.md` §4) — без расхождений между этим файлом и конфигом.

## 1. Цвет

Переносится 1:1 из прототипа (Zan.dc.html:18-29) — палитра уже проверена в обеих темах, не меняем.

### Light (`[data-theme="light"]`)

| Токен           | Значение  | Назначение                                                  |
| --------------- | --------- | ----------------------------------------------------------- |
| `--bg`          | `#FBFAF8` | Фон страницы                                                |
| `--surface`     | `#FFFFFF` | Карточки, композер, модалки                                 |
| `--surface-2`   | `#F3F1EC` | Вложенные блоки (чипы, поле textarea)                       |
| `--ink`         | `#15191A` | Основной текст                                              |
| `--muted`       | `#6B7370` | Вторичный текст, плейсхолдеры, мета                         |
| `--line`        | `#E5E2DC` | Границы, разделители                                        |
| `--accent`      | `#2F6F5E` | Основной акцент (кнопки, ссылки, активные состояния)        |
| `--accent-ink`  | `#FFFFFF` | Текст поверх `--accent`                                     |
| `--accent-soft` | `#E9F1ED` | Фон акцентных блоков (сообщение пользователя, активный таб) |
| `--warn`        | `#8A5A1E` | Предупреждения, бейдж "ждёт уточнения"                      |
| `--warn-soft`   | `#F6EEE2` | Фон предупреждения                                          |
| `--danger`      | `#98342B` | Ошибки, удаление                                            |

### Dark (`[data-theme="dark"]`)

| Токен           | Значение  |
| --------------- | --------- |
| `--bg`          | `#111413` |
| `--surface`     | `#191D1B` |
| `--surface-2`   | `#212624` |
| `--ink`         | `#ECEFEC` |
| `--muted`       | `#99A19D` |
| `--line`        | `#2B302E` |
| `--accent`      | `#55A98F` |
| `--accent-ink`  | `#0E1413` |
| `--accent-soft` | `#1C2724` |
| `--warn`        | `#D2A165` |
| `--warn-soft`   | `#2A2419` |
| `--danger`      | `#E0796D` |

**Правило:** в коде компонентов — только `bg-[var(--surface)]`/`text-[var(--ink)]` через Tailwind-маппинг (`colors.surface = "var(--surface)"` и т.д. в `tailwind.config`), никогда `#fff`/`#191D1B` напрямую. Danger-состояния (кнопка удаления, ошибка) — только через `--danger`, не через отдельный "красный", который не переключается в dark.

**Контраст:** `--muted` на `--surface`/`--bg` в обеих темах должен оставаться ≥ 4.5:1 — при добавлении нового использования `--muted` на новом фоне проверять отдельно, не считать проверенным по умолчанию.

### Spotlight-градиент (маркетинговый акцент, добавлено при запросе на Тарифы)

Три цветовые точки для **одной** анимированной градиентной заливки — не самостоятельные токены фона для обычных карточек, а материал только для `Card tone="spotlight"` (единственный на экран элемент, который должен цеплять взгляд, например «свой набор» в Тарифах). Светлота/насыщенность подобрана в том же диапазоне, что и `--accent-soft`/`--warn-soft` (два из трёх стопов — это они и есть), чтобы `--ink`-текст поверх градиента оставался читаемым без отдельной проверки под каждый кадр анимации.

| Токен            | Light     | Dark      | Назначение                                             |
| ---------------- | --------- | --------- | ------------------------------------------------------- |
| `--spotlight-1`   | `#E9F1ED` | `#1C2724` | = `--accent-soft` (зелёный стоп)                        |
| `--spotlight-2`   | `#F6EEE2` | `#2A2419` | = `--warn-soft` (золотой стоп)                          |
| `--spotlight-3`   | `#E8EEF6` | `#1B2430` | Новый — бледный синий стоп, третий цвет "микса"         |

Реализация — `.tone-spotlight` в `shared/styles/index.css`: `linear-gradient(120deg, var(--spotlight-1), var(--spotlight-2), var(--spotlight-3))` с `background-size: 200% 200%` и медленной (8s) анимацией `background-position` — эффект мягкого перелива, не мигающая реклама. Анимация подчиняется общему правилу `prefers-reduced-motion` (§7/§9), отдельно её обнулять не нужно.

## 2. Типографика

Шрифты — как в прототипе (Zan.dc.html:13): **Manrope** (UI-текст, основной), **IBM Plex Mono** (мета-данные, лейблы, цены, статусы — акцидентный моноширинный). Не добавлять третий шрифт без пересмотра этого документа.

```
font-sans: "Manrope", system-ui, sans-serif
font-mono: "IBM Plex Mono", monospace
```

Базовый размер — `16px`, line-height по умолчанию `1.5` (Zan.dc.html:37).

Прототип использовал произвольные инлайн-размеры (34/28/26/23/22/20/19/17/16/15/14/13/12/11px россыпью). Консолидируем в контролируемую шкалу — новые размеры не изобретаются мимо неё:

| Токен        | Размер | Line-height | Вес     | Шрифт         | Использование                                                                              |
| ------------ | ------ | ----------- | ------- | ------------- | ------------------------------------------------------------------------------------------ |
| `display`    | 34px   | 1.15        | 700     | Manrope       | Заголовок пустого состояния чата                                                           |
| `h1`         | 28px   | 1.2         | 700     | Manrope       | Заголовок страницы (История, Настройки)                                                    |
| `h2`         | 22px   | 1.25        | 700     | Manrope       | Заголовок секции внутри страницы                                                           |
| `h3`         | 17px   | 1.3         | 700     | Manrope       | Заголовок карточки/блока                                                                   |
| `body-lg`    | 17px   | 1.5         | 400     | Manrope       | Подзаголовок под h1                                                                        |
| `body`       | 15px   | 1.5         | 400     | Manrope       | Основной текст (сообщения, описания)                                                       |
| `body-sm`    | 14px   | 1.5         | 400/600 | Manrope       | Вторичный текст, лейблы полей                                                              |
| `caption`    | 13px   | 1.5         | 400/600 | Manrope       | Подписи, превью, вспомогательный текст                                                     |
| `micro-mono` | 11px   | 1.4         | 400/500 | IBM Plex Mono | Мета (даты, статусы, теги, цена в мелком виде), обычно uppercase + `letter-spacing: .03em` |

**Правило:** любой новый текстовый узел — это один из токенов таблицы, а не `font-size: 18px` руками. Если нужного размера нет — сначала добавляется строка в эту таблицу с обоснованием (не как одноразовое исключение в компоненте).

Минимальный размер тела текста — 13px (`caption`). Ничего мельче для читаемого текста (микро-моно 11px — только для коротких меток, не для предложений).

## 5. Тень

Одна тень на светлую и тёмную тему (уже задана в прототипе, Zan.dc.html:22,28) — не плодить новые. Как и остальные токены (§1), это **одно имя переменной**, значение которой переопределяется под `[data-theme="dark"]` — не два разных имени на светлую/тёмную версию:

```css
[data-theme="light"] {
  --shadow-card: 0 1px 2px rgba(20, 25, 23, 0.05), 0 8px 24px rgba(20, 25, 23, 0.05);
}
[data-theme="dark"] {
  --shadow-card: 0 1px 2px rgba(0, 0, 0, 0.3), 0 8px 24px rgba(0, 0, 0, 0.28);
}
--shadow-modal: 0 20px 60px rgba(0, 0, 0, 0.28); /* фиксированная, не завязана на тему — модалки всегда на затемнённом оверлее */
```

## 6. Z-index

В прототипе z-index раскиданы вручную по месту использования (header sticky `20`, композер `15`, оплата `40`, редактор тарифа `45`, онбординг `50`, подтверждение `60` — Zan.dc.html:39,399,483,444,536,430). Формализуем в шкалу, чтобы новый оверлей не выбирался наугад:

| Токен            | Значение | Использование                                                                |
| ---------------- | -------- | ---------------------------------------------------------------------------- |
| `z-sticky`       | 20       | Sticky header                                                                |
| `z-composer`     | 15       | Fixed композер внизу                                                         |
| `z-overlay`      | 40       | Обычная модалка (оплата, свой набор)                                         |
| `z-overlay-high` | 50       | Модалка поверх другой модалки (онбординг)                                    |
| `z-overlay-top`  | 60       | Confirm-модалка (всегда самая верхняя — подтверждение необратимого действия) |
| `z-toast`        | 70       | Toast-уведомления — новый уровень, в прототипе не было тостов                |

**Правило:** новый оверлей = выбор из этой таблицы, а не `z-index: 9999`.

## 7. Breakpoints

В прототипе не заданы явно (это был десктоп-ориентированный мокап с `max-width: 1080px`, Zan.dc.html:40,62). Продукт — mobile-first (бриф §2), поэтому breakpoints фиксируем отдельно, начиная с мобильного как базового:

| Токен               | Ширина | Layout-следствие                                                                    |
| ------------------- | ------ | ----------------------------------------------------------------------------------- |
| base (без префикса) | 0px    | Мобильный, один столбец, нав может уходить в нижний таб-бар                         |
| `sm`                | 640px  | Композер шире, чипы быстрых тем в 2 ряда вместо колонки                             |
| `md`                | 768px  | Полная навигация в шапке вместо таб-бара, сетка тарифов 2 колонки                   |
| `lg`                | 1024px | Settings: боковые табы + контент рядом (как в прототипе), сетка тарифов 3-4 колонки |
| `xl`                | 1280px | Контейнер выходит на `max-width: 1080px` с центрированием (как в прототипе)         |

Ни одна страница не должна давать горизонтальный скролл на `base`.

## 8. Иконки

`lucide-react`, сетка 16/20/24px, `stroke-width: 2` (дефолт библиотеки — не переопределять руками без причины).

- Любая иконка-кнопка без подписи рядом — обязателен `aria-label` (в прототипе иконки — самодельные `div`-примитивы без подписи, Zan.dc.html:409,416,422 — так делать нельзя).
- Не эмодзи вместо иконок нигде в интерфейсе.

## 9. Touch targets

Минимум 44×44px для любого интерактивного элемента (кнопки, чипы, иконки-кнопки), минимум `space-2` (8px) между соседними — уже зафиксировано в `PLAN.md` §7 как чек-лист Stage 5, здесь — как обязательное свойство при вёрстке, не только как пункт аудита постфактум.

---

## 10. Правило изменения токенов

Токен меняется в этом файле → сразу переносится в `tokens.css`/`tailwind.config` в том же PR → все места, использовавшие старое значение, обновляются (см. `CODING_STANDARDS.md` §3 — чистая замена, не два значения одновременно). Отдельный токен "просто на этот случай, руками в компоненте" — запрещён.
